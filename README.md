Bloom Bastion is an original browser arena-survival game. You are the Guardian Wisp: defend the Great Bloom at the center of the arena from waves of geometric blight creatures, build your score, and pick 1 of 3 upgrades between waves. Survive to wave 10 to win, then keep going in endless mode. Move with WASD or the arrow keys, aim with the mouse, hold click or Space to shoot, P pauses, M mutes. No build step and no network calls: the whole game runs from static files under `game/`, with WebAudio sound generated in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. To hand the entry in exactly as the grader does: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
